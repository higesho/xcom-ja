# X-COM: UFO ディフェンス 日本語化パッチ

Steam 版「X-COM: UFO Defense」（UFO: Enemy Unknown）を日本語で遊べるようにする、非公式のファンメイド日本語化パッチです。
開発元・販売元とは関係ありません。

- サイト（紹介・入れ方）: https://higesho.github.io/xcom-ja/
- ダウンロード: [リリース](https://github.com/higesho/xcom-ja/releases/latest) の `XCOM_UFODefense_JP.zip`
- 日本語化プロジェクトの一覧: https://higesho.github.io/ja/

## 入れ方

1. `XCOM_UFODefense_JP.zip` の中の `winmm.dll` を、ゲームのフォルダ（`dosbox.exe` があるフォルダ）に置きます。
2. いつもどおり Steam から起動し、最初の言語の選択で「日本語」を選びます。

外すときは、`winmm.dll` を消せば英語版に戻ります。
ゲームのファイルは書き換えません。配布物には原作のプログラムやデータは入っていません。
