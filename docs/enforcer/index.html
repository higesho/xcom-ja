日本語化プロジェクト

X-COM: Enforcer

X-COM: エンフォーサー 日本語化パッチ

Steam 版の「X-COM: Enforcer」を日本語で遊べるようにする、非公式のファンメイド日本語化パッチです。 メニューやエンフォーサーの選択、研究（武器とパワーアップの強化）の画面、ステージの名前と目標、画面のメッセージ、オプションまで、ゲームの中の文章を日本語にしています。 ゲームの System フォルダにファイルをひとつ置くだけで日本語になり、消せば英語に戻ります。

ダウンロード（GitHub）

どんなゲーム？

X-COM: エンフォーサーは、2001年にインフォグラムズ（マイクロプローズ）が発売した X-COM シリーズの外伝で、Unreal エンジンを使ったアクション・シューティングです。

異星人が地球の街を襲い、X-COM の科学者が作った戦闘ロボット「エンフォーサー」が出撃します。 キャンプ場やボウリング場、港、空港、北極基地などで、セクトイドやミュートン、リーパーといったおなじみの異星人を倒していきます。

敵を倒して集めたデータポイントで研究を進め、武器やパワーアップ、エンフォーサー自身の能力を強化できます。協力プレイや対戦のマルチプレイもあります。

入れ方

  1. ダウンロードした XCOM_Enforcer_JP.zip の中の winmm.dll を、ゲームの System フォルダ（XCom.exe があるフォルダ）に置きます。Steam のライブラリでゲームを右クリックし、「管理」→「ローカルファイルを閲覧」で開いたフォルダの中の System です。
  2. いつもどおり Steam から起動します。

ゲームのファイルは書き換えません。日本語の文章と字のファイルは %LOCALAPPDATA%\XC_JP_ENF に作られます。

外し方

  • ゲームの System フォルダから winmm.dll を消します。

遊ぶときの注意

  • ムービーと、絵として描かれた文字（「NAME」「SKILL」「EMPTY」「LOCKED」「DATA POINTS」など）は英語のままです。音声には字幕がありません。
  • エンフォーサーの名前は英字で入力します。
  • Steam 版の Unreal エンジン（バージョン 420）に合わせてあります。中身が違うときは日本語化せずに英語のまま動きます。
  • ほかの X-COM の日本語化パッチとは別のファイルです。それぞれのゲームのフォルダに、それぞれの winmm.dll を置いてください。
